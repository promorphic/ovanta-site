Our thesis

The internet is getting a new kind of customer. It can't use a credit card.

Today's payment rails were built for humans: business hours, chargebacks, card numbers, KYC forms and settlement in days. Agents operate at machine speed, in machine-sized amounts, across every border at once. Stablecoins are the first money native to the internet, and the natural currency of software.

01

Agents can't open bank accounts

An AI agent can't walk into a branch or pass a card issuer's checks. A stablecoin wallet can be provisioned by code in milliseconds and governed by the business behind it.

02

Micropayments finally make sense

Card networks charge ~30¢ plus a percentage, which kills pay-per-call and pay-per-token. Stablecoin transfers cost fractions of a cent, so agents pay for exactly what they use.

03

Money that is programmable

Budgets, allowlists, escrow and conditional release live inside the money itself. Policies are enforced by code, not by a reconciliation team at month end.

04

Instant, final, always on

Agents don't sleep and neither should settlement. Stablecoins settle in under a second, 24/7, with finality. No batch windows, no weekend delays.

05

Global by default

A digital dollar works the same in Lagos, São Paulo and San Francisco. Agents can trade with anyone on the internet without correspondent banks or FX spreads.

06

Fully reserved, fully transparent

Regulated, dollar-backed stablecoins redeem 1:1 and are auditable on-chain. The stability of the dollar, on the rails of the internet.

The platform

Everything an agent needs to transact safely

One API to give agents money, and one dashboard for humans to stay in control.

Agent Wallets

Provision a managed or self-custodied USDC wallet per agent, per task or per user with a single call. MPC key security, no seed phrases.

Spend Policies

Daily caps, merchant allowlists, velocity limits and human approval above a threshold. Enforced before a transaction is signed.

Nanopayments

Pay-per-request down to $0.0001 using HTTP 402 payment flows. Monetize APIs, data and content for agent traffic with no signup.

Fiat On / Off Ramps

Fund agent treasuries from a bank account and sweep earnings back in 40+ currencies. Stablecoins in the middle, dollars at the edges.

Ledger & Audit

Every payment is tagged with the task, agent and principal that caused it. Export to your ERP or query in real time.

Multi-chain Routing

Ethereum, Base, Solana, Arbitrum, Polygon and Avalanche. Each payment is routed to the fastest, cheapest rail automatically.

agent.tsagent.py 
import { Ovanta } from "@ovanta/sdk";

const ovanta = new Ovanta({ apiKey: process.env.OVANTA_KEY });

// 1. Provision a wallet for this agent
const wallet = await ovanta.wallets.create({
  agentId: "research-agent-07",
  currency: "USDC",
});

// 2. Guardrails, enforced before signing
await wallet.policies.set({
  dailyLimit: 50_00,          // $50.00
  perTxMax:   5_00,           // $5.00
  requireApprovalAbove: 25_00,
});

// 3. Pay for a resource, per request
const res = await wallet.fetch("https://api.data.xyz/v1/prices");
// → 402 handled · paid $0.0021 · settled in 0.38s
