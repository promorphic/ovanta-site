Our thesis

The internet has a new customer. It can't use a credit card.

Payment rails were built for humans: business hours, chargebacks, card numbers and settlement in days. Agents operate at machine speed, in machine-sized amounts, across every border at once. Stablecoins are the first money native to the internet, and the natural currency of software.

01

Agents can't open bank accounts

A stablecoin wallet can be provisioned by code in milliseconds and governed by the business behind the agent.

02

Micropayments finally work

Cards cost ~30¢ plus a percentage. Stablecoin transfers cost fractions of a cent, so agents pay for exactly what they use.

03

Money that is programmable

Budgets, allowlists and escrow live inside the money itself, enforced by code rather than month-end reconciliation.

04

Instant, final, always on

Agents don't sleep and neither should settlement. Sub-second finality, 24/7, with no batch windows.

05

Global by default

A digital dollar works the same everywhere. No correspondent banks, no FX spreads, no borders.

06

Fully reserved, transparent

Regulated, dollar-backed stablecoins redeem 1:1 and are auditable on-chain.

agent.tsagent.py
import { Ovanta } from "@ovanta/sdk";

const ovanta = new Ovanta({ apiKey: process.env.OVANTA_KEY });

// 1. Provision a wallet for this agent
const wallet = await ovanta.wallets.create({
  agentId: "research-agent-07",
  currency: "USDC",
});

// 2. Guardrails, enforced before signing
await wallet.policies.set({
  dailyLimit: 50_00,          // $50.00
  perTxMax:   5_00,           // $5.00
  requireApprovalAbove: 25_00,
});

// 3. Pay for a resource, per request
const res = await wallet.fetch("https://api.data.xyz/v1/prices");
// → HTTP 402 handled automatically, paid in USDC
